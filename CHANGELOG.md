# Changelog

All notable changes to OrthoDrift are documented here.

## 0.1.0 — 2026-08-10

- Shipped typed grapheme mutation provenance and registered rule validation.
- Added deterministic Unicode-word BM25 retrieval with stable tie breaking.
- Added ddmin, one-minimal enforcement, bounded global-minimum proof, and full
  trial retention.
- Added strict versioned case and experiment-run schemas, canonical JSONL,
  atomic no-clobber publication, runtime/engine fingerprints, and exact replay.
- Added the verified standalone offline report and report CLI.
- Bounded untrusted case/artifact inputs and documented the security boundary.
- Locked the Python and Chromium evidence environments with hashes/digests.
- Added real CLI, desktop, mobile, full-page, GIF, chart, provenance, reduction,
  architecture, artifact, and manifest evidence.
- Added exact Python 3.11–3.14 compatibility, clean-wheel, CodeQL-ready, and
  read-only visual drift workflows.

The committed Şəki example remains a synthetic lexical counterexample, not a
broad benchmark or native-language evaluation.
